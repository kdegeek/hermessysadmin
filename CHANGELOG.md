# Changelog

## 0.2.0 — 2026-11-06

Windows/AD RMM release: fleet, catalog, remote access and monitoring.

- **Fleet:** `fleet_inventory`, `fleet_device` and `fleet_history` probe every enabled AD computer (online state, disk, uptime, pending reboot, patch age, Defender, BitLocker, RDP/NLA) and keep snapshots. New Fleet tab with filters, multi-select and a device drawer.
- **Catalog:** 231 vetted PowerShell entries across 14 categories (195 read-only, 36 that change something), run through `catalog_search`, `catalog_get` and `catalog_run` (and `/ad catalog`, `/ad run`). New Catalog tab with generated parameter forms, a target picker, preview and result tables. The README table is generated by `scripts/catalog_table.py`.
- **Remote access:** `remote_sessions`, `remote_access_check`, `remote_assist_command` and `remote_shadow_command`, plus ten `remote.*` catalog entries that fix failing checks.
- **Monitoring:** `monitoring_enable`, `monitoring_status` and `monitoring_disable` manage a Hermes cron job that reports new and resolved findings; six new alert settings.
- **Safety:** fleet escalation (more than 10 targets, an OU, no explicit computers or any domain controller makes a write high-risk) and typed confirmation only for `destructive: true` entries.
- **Gallery modules:** the pinned-module machinery (lock with per-file SHA256, hardened module root, offline drop) ships, but no Gallery modules do, because Gallery functions fail on the WinRM double hop. Every entry uses in-box modules and `catalog_module_install` is disabled while the lock is empty.
- Three new skills: `fleet-health-check`, `endpoint-triage`, `remote-assist`; the four AD skills now point at helpful catalog entries.
- **Local transport:** new `transport` setting (`auto`/`local`/`winrm`). On a domain-joined Windows machine Hermes runs one persistent local PowerShell process instead of going through a WinRM jump host, so every DC and endpoint is one hop. `run_as` picks the account: `account` (runas /netonly with the configured username and password; the password goes only to `CreateProcessWithLogonW`) or `hermes_user`. Scripts that read DC-local state (SYSVOL, DNS server, replication metadata, GPO backups, time skew) target a domain controller through new prelude helpers (`Get-HermesDc`, `Invoke-HermesOnDc`, `Get-HermesDcTarget`, `Get-HermesSysvolPath`). `ad_connection_test`, the dashboard header and the setup card show the transport, run-as choice, local identity and network identity. `scripts/verify_live.py` uses the same transport selection.
  - **Upgrade note:** `auto` picks `local` on a domain-joined Windows host even when a WinRM jump host is configured. Set `transport: winrm` to keep the previous behaviour.
  - Run-as credentials are checked once with `LogonUserW`. A rejected password (or a locked, disabled or expired account) stops the transport until the settings change, so it cannot lock the account out. One authenticated LDAP read after start explains a missing network credential (for example, an SSH key-auth session with `hermes_user`). The PowerShell process gets an allowlisted environment and runs in a kill-on-close job object.
- **Overview and Ask Hermes:** the overview opens with a health score and a ranked "needs attention" list built from the live data. Each item, the device drawer and every catalog entry have an **Ask Hermes** button that opens a new chat with a ready prompt (right skill, read-only first) for you to review and send. Charts use severity colours, sparklines show area and the latest point, and the Catalog tab shows a summary, descriptions and a safety column.
- **Preview for every write:** the confirm dialog shows the script's `-Preview` plan for every change that has one, not only high-risk ones. The decision API reports `can_preview`.
- **Instant dashboard:** every view (overview, fleet, monitoring, device drawer, remote checks) answers from the last collected snapshot and refreshes in the background, with its age and a "refreshing…" note. A background collector in the gateway keeps them warm: the overview every minute, the fleet every five minutes and every online computer's drawer every twenty while the dashboard is in use. The local transport runs a pool of four PowerShell processes sharing one run-as credential check, so a slow probe never blocks a click. Warm views and drawers open in under 0.3 s (they took 3–17 s).
- **Fix:** monitoring status read `hermes cron list` with the Windows code page, so it showed an active job as disabled and a second enable could create a duplicate job. The CLI output is now decoded as UTF-8.
- `scripts/verify_live.py` now covers fleet, remote access, monitoring status and every read-tier catalog entry, still strictly read-only. It also runs every endpoint write and three DC writes with `-Preview` only (nothing changes), and `--only <op> --args '<json>'` runs one read op and prints its envelope.
- **Catalog safety review:** workstation-only guards on `stop_process`, `enable_firewall_profiles` and `remove_stale_profiles`; `clear_wu_cache` and `empty_recycle_bin` refuse domain controllers; `disable_stale_computers` skips AZUREADSSOACC and accounts with service SPNs; `disable_smb1_server` checks SMB1 audit events first; `gpo.settings_search` and `gpo.scripts` hide secrets and script arguments; `gpo.client_status` reads unsigned FILETIME halves.
- New blueprint icon (`assets/icon.svg`) and banner (`assets/banner.png`); README screenshots are dark and redacted.

## 0.1.0 — 2026-11-11

First release (Nous Research Hermes Agent Plugin Hackathon).

- 56 typed tools across six toolsets: domain, users, Group Policy, RDP, Windows Server Backup, meta. One of them, the raw PowerShell escape hatch (`ad_powershell`), is opt-in and off by default.
- Tiered safety policy (read / write / high-risk / protected), strict, permissive and read-only modes, privileged-group and domain-controller escalation, protected objects (matched by name, DN and SID) and privileged groups (matched by name, SID and GUID).
- Approval through Hermes's `pre_tool_call` hook, with previews for high-risk changes and no truncation of the arguments or script a human approves; local SQLite audit log with password redaction.
- Seven workflow skills and the `/ad` slash command.
- Hermes Desktop dashboard: Overview, Users, Group Policy, Remote Access, Backups, Audit. Dashboard writes require confirmation, and high-risk ones a typed object name.
- Opt-in live test suite (`SYSADMIN_LIVE=1`) and GitHub Actions CI.
