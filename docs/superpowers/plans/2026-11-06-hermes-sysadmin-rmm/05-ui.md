### Task 12: SVG chart components

**Files:**

**Interfaces:**
- Geometry, as plain function declarations:
  - `donutArcs(values: number[], r: number, inner: number) -> [{d: string, start: number, end: number, value: number, pct: number}]`. Each `d` is an SVG path centred at (0,0), starting at 12 o'clock and going clockwise. Zero values produce no arc. A single non-zero value produces a full ring as two arcs (an SVG arc can't draw 360°).
  - `barWidths(values: number[], max: number | null, width: number) -> number[]`. When `max` is null, use the largest value. The result is clamped to [0, width]. A non-zero value gets at least 2 px.
  - `histogramBins(values: number[], edges: number[]) -> number[]` returns counts per `[edges[i], edges[i+1])`; the last bin is open-ended (`>= edges[last]`). Null values are skipped.
  - `sparkPath(points: number[], width: number, height: number) -> string`. A polyline path `M…L…` scaled to the box. A flat series is drawn at mid-height. Fewer than 2 points gives `''`.
  - `seriesColor(i: number) -> string` returns `var(--hs-series-<i % 6>)`.
- CSS defines `--hs-series-0..5` on `.hs-root`, all from `--ui-*` tokens: `--ui-accent`, `--ui-success`, `--ui-warning`, `--ui-danger`, `--ui-info`, `--ui-muted-foreground`. Check which `--ui-*` tokens the existing CSS uses and pick six that exist, falling back with `var(--ui-x, var(--ui-y))`.
- Components (all return `jsx('figure', { className: 'hs-chart', role: 'img', 'aria-label': <data as text>, ... })`):
  - `Donut({ data: [{label, value, onClick?}], size = 140, center?: string })`. A legend lists `label value (pct%)`; legend rows and arcs are clickable when `onClick` is set.
  - `BarList({ data: [{label, value, display?, tone?, onClick?}], max?, unit? })`. Horizontal bars with the label on the left and the value text on the right.
  - `Histogram({ data: [{label, value, onClick?}], height = 120 })`. Vertical bars with the count above each and the label below.
  - `StackedBar({ data: [{label, value, onClick?}] })`. A single 100% bar plus a legend with counts.
  - `Sparkline({ points: number[], width = 160, height = 36, label, valueText })`.
  - `StatTile({ label, value, sub?, tone?, onClick? })`. A thin wrapper over `Kpi` that keeps the tile size consistent.
  - The aria-label format is `"<title>: a 3, b 5, c 0"`. Each chart takes an optional `title` used there.
